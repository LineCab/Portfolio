# Portfolio — Line Cabaret

Portfolio de Line Cabaret, designer UI/UX.

## Pages

| Fichier         | Page      |
| --------------- | --------- |
| `index.html`    | Accueil   |
| `projets.html`  | Projets   |
| `a-propos.html` | À propos  |

Chaque page est un export autonome (HTML, images, police et scripts embarqués dans le fichier) : il suffit d'ouvrir `index.html` dans un navigateur, sans serveur ni installation.

La navigation (en-tête, logo, boutons « Voir tous mes projets » et « En savoir plus sur moi ») relie les trois pages entre elles par des liens relatifs, ce qui permet de publier le dossier tel quel, par exemple avec GitHub Pages.
